First, meet the three models

Cloud services let you access computing resources through the internet. The main difference is how much you manage yourself.

Remember: I · P · S
🖥️

IaaS

Infrastructure as a Service

Rent virtual computers, storage and networking. You have more control and manage the operating system and applications you use.

Examples
Amazon EC2 · Azure Virtual Machines · Google Compute Engine
🧰

PaaS

Platform as a Service

Use a ready-made online platform to build, test and deploy applications without managing the underlying servers.

Examples
Google App Engine · Azure App Service · Heroku
📄

SaaS

Software as a Service

Use a complete application over the internet. The provider manages the software platform and infrastructure.

Examples
Google Docs · Gmail · Microsoft 365 · Dropbox
💡 Think of a workshop: IaaS is like renting the space and equipment and setting things up yourself. PaaS is like using a ready-equipped workshop to build something. SaaS is like using a finished product that is ready to go.
